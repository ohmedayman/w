# واتساب جماعي - WhatsApp Bulk Sender

أداة إرسال رسائل جماعية على واتساب بواجهة ويب سهلة الاستخدام.

## المميزات

- إرسال رسائل نصية جماعية
- إرسال صور وفيديوهات وملفات
- إدارة العملاء (إضافة/تعديل/حذف)
- إضافة أرقام متعددة بلصق مباشر
- قوالب رسائل جاهزة (8 قوالب)
- استيراد العملاء من ملف CSV
- واجهة عربية سهلة الاستخدام

## التشغيل المحلي (الأسهل والأفضل)

### المتطلبات
- Node.js (الإصدار 14 أو أعلى) - [تحميل Node.js](https://nodejs.org)
- واتساب على الهاتف

### خطوات التشغيل

```bash
# 1. نسخ المشروع
git clone https://github.com/ohmedayman/w.git
cd w

# 2. تثبيت المكتبات
npm install

# 3. تشغيل البرنامج
npm start
```

### فتح البرنامج
افتح المتصفح على:
```
http://localhost:3000
```

## كيفية الاتصال بواتساب

1. عند فتح البرنامج، سيظهر كود QR في Terminal
2. افتح واتساب على هاتفك
3. اذهب إلى: **الأعلى > الأجهزة المرتبطة > ربط جهاز**
4. امسح الكود
5. جاهز! يمكنك البدء في إرسال الرسائل

## كيفية استخدام البرنامج

### 1. إضافة العملاء

#### طريقة يدوية:
- أدخل اسم العميل ورقم الهاتف واضغط "إضافة"

#### طريقة لصق متعددة (الأسهل):
- انسخ الأرقام من أي مكان
- الصقها في مربع "إضافة أرقام متعددة"
- كل رقم في سطر أو مفصول بفاصلة
- اضغط "إضافة الكل"

مثال:
```
01012345678
01123456789
01234567890
```

#### طريقة CSV:
- أعد ملف CSV بالشكل:
```csv
الاسم,الهاتف
أحمد محمد,01012345678
سارة علي,01123456789
```

### 2. إرسال الرسائل

- اختر قالب جاهز أو اكتب رسالة مخصصة
- استخدم المتغيرات:
  - `{name}` - اسم العميل
  - `{phone}` - رقم الهاتف
- ارفق ملف (صورة/فيديو/PDF) اختياريًا
- حدد العملاء واضغط "إرسال"

### 3. القوالب الجاهزة

| القالب | الاستخدام |
|--------|-----------|
| رسالة ترحيب | للعملاء الجدد |
| عرض خاص | للمنشنات والعروض |
| تذكير | لتذكير العملاء |
| متابعة | لمتابعة العملاء |
| شكر وتقدير | بعد الشراء |
| منتج جديد | لإطلاق منتج |
| خصم حصري | لعملاء VIP |
| دعوة لحدث | للفعاليات |

## لماذا لا يعمل على Vercel؟

WhatsApp Web.js يحتاج متصفح (Puppeteer) عشان يتواصل مع واتساب، وده مش متاح على Vercel.

**البدائل:**
1. **التشغيل المحلي** - الأفضل والأكثر أمانًا
2. **استخدام VPS** - مثل DigitalOcean أو AWS
3. **استخدام Render.com** - يدعم Node.js apps

## تنبيهات مهمة

- لا ترسل رسائل كثيرة في وقت قصير لتجنب حظر حسابك
- يُنصح بانتظار ثانيتين على الأقل بين كل رسالة
- استخدم القوالب بذكاء لتخصيص الرسائل لكل عميل

## استكشاف الأخطاء

### WhatsApp لا يتصل
- تأكد من أن واتساب على هاتفك محدث
- حاول مسح الكود مرة أخرى
- أعد تشغيل البرنامج

### الرسائل لا تُرسل
- تأكد من صحة أرقام الهواتب (يبدأ بـ 0)
- تأكد من أن الحساب غير محظور

### خطأ npm
- امسح مجلد `node_modules` وأعد التثبيت:
```bash
rm -rf node_modules
npm install
```
