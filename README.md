# واتساب جماعي - WhatsApp Bulk Sender

أداة إرسال رسائل جماعية على واتساب - تعمل من المتصفح مباشرة

## جرب الآن

**https://w-rho-five.vercel.app**

## المميزات

- إرسال رسائل واتساب مباشرة من المتصفح
- إضافة أرقام متعددة بلصق مباشر
- قوالب رسائل جاهزة (8 قوالب)
- استيراد عملاء من ملف CSV
- إدارة العملاء (إضافة/حذف/تحديد)
- حفظ البيانات في المتصفح (localStorage)

## كيف يعمل

1. أضف عملاءك (يدويًا أو بلصق أو CSV)
2. اكتب الرسالة أو اختر قالب جاهز
3. حدد العملاء
4. اضغط "إرسال" - هيفتح واتساب مع كل عميل

## القوالب الجاهزة

| القالب | الاستخدام |
|--------|-----------|
| ترحيب | للعملاء الجدد |
| عرض خاص | للعروض والتخفيضات |
| تذكير | لتذكير العملاء |
| متابعة | لمتابعة العملاء |
| شكر وتقدير | بعد الشراء |
| منتج جديد | لإطلاق منتج |
| خصم حصري | لعملاء VIP |
| دعوة لحدث | للفعاليات |

## المتغيرات

- `{name}` - اسم العميل
- `{phone}` - رقم الهاتف

مثال: `مرحبا {name}! نتمنى لك يوماً سعيداً`

## التشغيل المحلي (اختياري)

```bash
git clone https://github.com/ohmedayman/w.git
cd w
npx serve public
```

- HTML/CSS/JavaScript فقط
