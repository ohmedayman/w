# واتساب جماعي - WhatsApp Bulk Sender

أداة إرسال رسائل جماعية على واتساب بواجهة ويب سهلة الاستخدام.

## المميزات

- إرسال رسائل نصية جماعية
- إرسال صور وفيديوهات وملفات
- إدارة العملاء (إضافة/تعديل/حذف)
- استيراد العملاء من ملف CSV
- قوالب رسائل جاهزة
- واجهة عربية سهلة الاستخدام

## المتطلبات

- Node.js (الإصدار 14 أو أعلى)
- npm

## التثبيت

1. افتح مجلد المشروع في Terminal:

```bash
cd "F:\واتساب"
```

2. ثبتي المكتبات:

```bash
npm install
```

3. شغّل البرنامج:

```bash
npm start
```

4. افتح المتصفح على:

```
http://localhost:3000
```

## كيفية الاستخدام

### 1. الاتصال بواتساب
- عند فتح البرنامج، سيظهر كود QR
- افتح واتساب على هاتفك
- اذهب إلى: الأعلى > الأجهزة المرتبطة > ربط جهاز
- امسح الكود

### 2. إضافة العملاء
- يمكنك إضافة عملاء يدويًا
- أو استيراد ملف CSV بالشكل التالي:

```csv
الاسم,الهاتف
أحمد محمد,01012345678
سارة علي,01123456789
```

### 3. إرسال الرسائل
- اكتب نص الرسالة
- يمكنك استخدام المتغيرات:
  - `{name}` - اسم العميل
  - `{phone}` - رقم الهاتف
- ارفق ملف (صورة/فيديو/PDF) اختياريًا
- حدد العملاء المراد إرسال الرسالة لهم
- اضغط "إرسال الرسائل"

### 4. قوالب الرسائل
- يمكنك حفظ قوالب رسائل لإعادة استخدامها
- مثال: قالب ترحيب، قالب عروض، إلخ

## تنبيهات مهمة

- لا ترسل رسائل كثيرة في وقت قصير لتجنب حظر حسابك
- يُنصح بانتظار ثانيتين على الأقل بين كل رسالة
- استخدم القوالب بذكاء لتخصيص الرسائل لكل عميل

## استكشاف الأخطاء

### Problem: WhatsApp غير يتصل
- تأكد من أن واتساب على هاتفك محدث
- حاول مسح الكود مرة أخرى

### Problem: الرسائل لا تُرسل
- تأكد من صحة أرقام الهواتب
- تأكد من أن الحساب غير محظور

### Problem: خطأ في الاتصال
- أعد تشغيل البرنامج
- امسح ملفات الجلسة في مجلد `data/wwebjs_auth`
